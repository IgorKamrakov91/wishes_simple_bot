# Варианты аватара бота

Открой `preview.png` (или `preview.html` в браузере): каждый вариант в круге, как его обрезает Telegram,
в размерах 48 и 32 px и на тёмной теме. `0-current.jpg` — текущий аватар для сравнения.

| Файл | Идея |
|---|---|
| `1-gift-reserved` | Подарок с зелёной галочкой: «подарок забронирован». Фиолетовый фон. |
| `2-wishlist-card` | Карточка-список с бантом: сразу читается как вишлист. Коралловый фон. |
| `3-telegram-bubble` | Подарок в облачке сообщения, цвета Telegram: «подарки в Telegram». |
| `4-heart-bow` | Красный подарок с бантом-сердцем: тёплый, «от души». |
| `5-night-gold` | Тёмный фон, синий подарок с золотом и искрами: праздничный, премиальный. |
| `6-gift-tag` | Подарочная бирка с сердцем: про выбор и пометку подарка. |

У каждого варианта есть `.svg` (вектор, можно править цвета) и `.png` 640×640 для загрузки.
Загружается в BotFather: `/mybots` → бот → Edit Bot → Edit Botpic.
