# Ручная приёмка перед рекламой

Проходит человек в настоящем Telegram, а не тесты. Отмечай ✅ / ❌ и записывай, где пришлось думать или
что выглядело странно. Скриншоты непонятных мест — самое ценное.

Нужны три аккаунта: **Владелец**, **Гость А**, **Гость Б**. Для раздела 1 нужен аккаунт, который ещё
ни разу не писал боту: экран новичка показывается только тому, у кого нет ни своих, ни чужих списков.
Удалять ради проверки свои данные не нужно.

## 1. Новичок (Владелец)
- [ ] До «Старт» видно описание бота на русском; аватар — подарок с бантом-сердцем.
- [ ] `/start`: три шага «как это работает» и одна кнопка «Создать первый список».
- [ ] Меню команд (кнопка «/» или «Меню») на русском: Главное меню, Мои списки, Новый список, Отменить ввод, Помощь.
- [ ] `/help` объясняет, кто что видит, и называет @ikamrakov.

## 2. Список и подарки (Владелец)
- [ ] Создать список. Название длиннее 100 символов → понятная ошибка, ввод не сбрасывается.
- [ ] Подарок «название сначала»: название → «Сохранить без ссылки».
- [ ] Подарок «ссылка сначала»: прислать ссылку → бот просит название → подарок сохранён со ссылкой.
- [ ] Название `Lego.Technic` сохраняется как название, а не как ссылка.
- [ ] После сохранения есть «Добавить цену» / «Добавить описание»; цена «2 500 ₽» принимается, «две тыщи» — понятная ошибка.
- [ ] Начать добавление и нажать «Отмена» → в списке ничего не появилось.
- [ ] Карточка: кнопка «Открыть в магазине», превью ссылки.
- [ ] Навигация словами: «← Предыдущий / Следующий →», в списке больше 5 подарков — «Следующие →».
- [ ] Написать боту просто «привет» → подсказка и меню, а не тишина. Прислать фото во время ввода → «пришли текстом».

## 3. Отправка другу
- [ ] «Отправить другу» → выбор чата → в чат с Гостем А ушла карточка «🎁 … делится вишлистом …» с кнопкой «Открыть вишлист».
- [ ] «Скопировать ссылку» копирует ссылку `t.me/…?start=l_…`.

## 4. Гость А
- [ ] Кнопка в карточке открывает бота; если это первый раз, Telegram показывает «Старт» — после нажатия открывается список Владельца, ниже есть «Создать свой список».
- [ ] Забронировать подарок → карточка «Это твоя бронь… другие гости видят… твоё имя под спойлером».
- [ ] **Владельцу пришло уведомление** «В твоём списке … забронировали подарок …. Кто — не говорим.» (первая реальная проверка доставки).
- [ ] Гостю А уведомление о собственной брони не пришло.
- [ ] Нажать «Забронировать» на старом сообщении ещё раз → бронь не снялась.
- [ ] «Мои брони» в главном меню: подарок виден, «Снять бронь» работает, Владельцу пришло «сняли бронь».
- [ ] Снова забронировать этот подарок — он нужен занятым для раздела 5.

## 5. Гость Б (приватность)
- [ ] Открыть ссылку от Владельца (переслать её Гостю Б).
- [ ] Подарок Гостя А показан как «занято», имя Гостя А — под спойлером.
- [ ] Снять чужую бронь нельзя.
- [ ] В «Настройках» включить «Брони в списках друзей» → когда Гость А бронирует другой подарок, Гостю Б приходит уведомление без имени.
- [ ] Владелец в карточке видит «кто-то уже выбрал», но не имя.

## 6. Удаление и старые кнопки
- [ ] Владелец удаляет забронированный подарок → никому ничего не приходит; у Гостя А подарок пропал из «Моих броней».
- [ ] Нажать кнопку удалённого подарка в старом сообщении → всплывающее «удалён или недоступен», в чате не появляется сообщение об ошибке.
- [ ] Старая ссылка вида `?start=list_123` у постороннего → «ссылка устарела».

## 7. Группа
- [ ] Добавить бота в группу. `/my` в группе → только кнопка «Открыть бота», личные списки не видны.
- [ ] Обычные сообщения в группе бот игнорирует.
- [ ] Отправить карточку списка в группу через «Отправить другу» → кнопка открывает список в личке.

## 8. Устройства и крайние случаи
- [ ] iOS, Android, Desktop: кнопки читаются, ничего не обрезано.
- [ ] Крупный шрифт в настройках Telegram.
- [ ] Аккаунт без username бронирует → у других гостей под спойлером его имя.
- [ ] Очень длинное название подарка и списка.
- [ ] Telegram на английском: меню и описание бота всё равно русские.

## 9. Люди без подсказок
- [ ] 2–3 человека, которые не видели бота, создают список и бронируют подарок у друга. Не подсказывать; записать, где остановились.
